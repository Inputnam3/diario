# Manual do Usuário - Diário Fit

## 1. Introdução

Bem-vindo ao Diário Fit! Este manual foi projetado para ajudá-lo a utilizar todas as funcionalidades da plataforma de controle nutricional via WhatsApp de forma simples e eficiente.

## 2. Acesso à Plataforma

- **Login:** Como acessar a plataforma com seu email e senha.
- **Esqueci minha senha:** Como recuperar sua senha de acesso.

## 3. Painel Principal (Dashboard)

Uma visão geral da tela inicial após o login.

- **Visão Geral:** O que cada seção do painel principal representa.
- **Indicadores:** Entendendo os principais números (mensagens enviadas, status, etc.).

## 4. Funcionalidades Principais

### 4.1. Conversas

- **Iniciando uma nova conversa:** Como enviar uma mensagem para um novo número.
- **Visualizando o histórico:** Como acessar e pesquisar conversas anteriores.
- **Usando Templates de Mensagem:** (Se aplicável) Como usar mensagens pré-aprovadas para agilizar a comunicação.

### 4.2. Contatos

- **Visualizando Contatos:** Como ver a lista de contatos salvos.
- **Adicionando um novo Contato:** Como salvar um novo contato na plataforma.

## 5. Solução de Problemas Comuns

- **Mensagem não enviada:** O que fazer se uma mensagem falhar ao ser enviada.
- **Não consigo fazer login:** Passos para verificar problemas de acesso.
